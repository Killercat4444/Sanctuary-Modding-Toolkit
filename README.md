# Sanctuary-Modding-Toolkit
To be very clear, this was made with ChatGPt, this is a blender addon allowing for the import/export of meshes, textures, armatures, animations for SSS, this is meant as a mod creation tool.

This modding tool designed to make working with **Sanctuary: Shattered Sun** assets significantly easier, with direct support for Blender, vanilla game assets, animations, textures, and custom/modded content.

##  Model Import / Export
• Import vanilla Sanctuary models directly into Blender
• Export edited or completely custom models back into Sanctuary's model format
• Modify existing units or use vanilla models as starting points for entirely new units

##  Armature / Skeleton Import & Export
• Import vanilla Sanctuary skeletons and rigs
• Preserve bone hierarchies
• Preserve model skinning and bone assignments
• Edit existing rigs inside Blender
• Export custom or modified armatures for use in Sanctuary
• Create custom skeletons for completely new models

##  Animation Import / Export
• Import vanilla Sanctuary animations into Blender
• Edit existing animations
• Export custom or modified animations
• Use vanilla animations with custom/modded models
• Create animations for custom units and rigs

##  Animation Player / Previewer
• Browse available animations for a unit
• Play vanilla animations directly on the model
• Play custom/modded animations
• Preview animations without needing to launch Sanctuary
• Quickly test model, skeleton, and animation compatibility

##  Unit Browser
• Browse Sanctuary's vanilla units
• Search for specific units
• Select units directly through the tool
• Automatically locate assets associated with a unit
• Grab vanilla assets to use as starting points for mods

##  Integrated Game File Browser
• Browse Sanctuary's game files directly from inside the tool
• Jump from a selected unit directly to its relevant files
• Quickly locate and open a unit's Lua
• Quickly locate/open its LOD0 model
• Navigate related unit assets without manually searching through the game's folders and archives

##  Vanilla Asset Extraction
• Pull assets directly from Sanctuary's game files
• Extract models
• Extract animations
• Extract skeletons
• Extract textures
• Use extracted assets for modification or reference

This makes it much easier to reverse-engineer how existing Sanctuary units are built.

##  PNG → Sanctuary Texture Converter
• Import normal PNG textures
• Automatically convert them into the texture format Sanctuary expects
• Simplifies creating custom textures and unit retextures
• Removes the need to manually prepare every texture for the game

## Modded Asset Support
• Load both vanilla and custom/modded assets
• Preview modded models using the tool
• Preview custom animations
• Test modded assets alongside vanilla resources
• Use vanilla resources as bases for custom units
• Mix custom models with compatible vanilla skeletons/animations
